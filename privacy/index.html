Privacy

Privacy And Consent

Plain-language notes for BrendonRcoleman.com and the planned Letters of Light subscriber system.

Current Status

The Letters of Light signup form is not live until the subscriber service is deployed, configured, and health-checked. The current static form is disabled by default and does not send addresses anywhere.

Consent For Letters Of Light

The public website can invite interest, but visiting the site or entering an address after launch will not by itself make someone subscribed. The planned flow requires a confirmation step before an address is treated as opted in.

The planned subscriber system supports unsubscribe handling. Confirmation and unsubscribe tokens are handled by the private API service, then redirected to static status pages without token query parameters.

What The Site Contains

This static site contains public pages, public Letters, public writing, service pages, and navigation. It must not contain raw subscriber emails, private subscriber storage paths, tokens, provider secrets, or email service credentials.

The planned subscriber service stores subscriber state privately outside the public site. Provider selection and deployment details have not been published or approved here.

Contact

Until the owned signup flow is live, use the existing contact routes on the site for direct inquiries. Do not send private credentials, tokens, or sensitive account details through public page links.
